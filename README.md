# servicioautentication

Proyecto Spring Boot mínimo generado localmente (equivalente a Spring Initializr).

Requisitos:
- JDK 21
- Maven

Construir y ejecutar:

```powershell
mvn -v
mvn clean package
java -jar target/servicioautentication-0.0.1-SNAPSHOT.jar
```

Clase principal: `com.example.servicioautenticacion.ServicioAutenticacionApplication`
